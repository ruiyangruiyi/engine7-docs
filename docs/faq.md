# 常见问题

[返回文档首页](../README.md)

## 在哪里下载？需要装开发环境吗？

使用[官网下载页](https://www.twinsun.top/download/)的当前安装包。安装程序提供运行环境，无需单独安装 Node.js 或 Python；npm 自托管路线需要 Node.js 22+。

## 需要购买模型服务吗？

可以使用安装界面提供的免费档，也可以配置自己的模型服务。免费额度与服务范围以当前界面和官网为准；自配模型的费用、权限及用量由对应服务决定。

## 如何让它边做边汇报？

发送 `/work on`，在任务中说明“先给计划、过程中报告进展、先交中间结果”。如果仍看不到过程，检查当前渠道的过程显示和群聊设置。详见[交互任务](interactive-tasks.md)。

## /ps 和普通消息有什么区别？

`/ps` 专门用于当前任务运行期间，及时追加或改变要求。没有运行中的任务时，直接发普通消息；若 `/ps` 提示没有任务，先确认会话和任务状态。

## /stop 会撤销已做的事吗？

它停止当前会话的运行任务及待处理消息，不回滚已完成的外部操作。需要调整文件或已发送内容时，应另外交代恢复或修正。其他独立任务和定时安排需分别管理。

## 为什么 /tasks 没有列出正在回复的任务？

`/tasks` 显示后台任务列表。当前前台回答不一定在这个列表中，结合聊天进展、控制台和 `/agents` 查看状态。

## 模型报错以后为什么没有切换？

先 `/model` 检查是否手动固定了模型、是否配置了备用链、候选项是否全部冷却。再检查服务凭据、额度、网络和相应能力。需要恢复自动选择时使用 `/model auto`。具体见[Fallback 说明](models-and-fallback.md)。

## 换模型会清空伙伴记忆吗？

更换模型与删除或迁移工作区是不同操作。伙伴的配置、记忆和文件由部署环境保存；迁移电脑或重新配置前，应确认实际目录和备份。不要把重新配置当成单纯模型切换。

## 数据存在哪里？

Engine7 的工作区和持久状态存储在你部署的电脑或服务器上。调用外部模型或工具服务时，对应输入会发送给所配置的服务；数据处理范围取决于你的模型、工具及渠道设置。

## 启动或连接失败，如何排查？

1. 在控制台核对运行状态、安装版本和当前伙伴目录。
2. 检查所选模型的网络、凭据与额度，及聊天平台是否已完成授权或扫码。
3. 查看近期日志；npm 部署可运行 `engine7 --version` 和 `engine7 doctor`，记录版本与自检结果。
4. 将系统、版本、渠道、复现步骤及去掉敏感信息的错误摘要提交到 [Issues](https://github.com/ruiyangruiyi/engine7-docs/issues)。
