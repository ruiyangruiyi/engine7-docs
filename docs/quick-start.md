# 快速开始

[返回文档首页](../README.md)

## 路线一：安装程序

适合希望通过图形向导配置伙伴的用户。

1. 打开[官网下载页](https://www.twinsun.top/download/)，选择对应系统和架构的安装包。Mac 请区分 Apple Silicon 与 Intel。
2. 按安装向导选择伙伴、模型与聊天平台。安装程序提供运行环境，无需另行安装 Node.js 或 Python。
3. 按所选平台的提示完成授权或扫码，打开控制台确认运行状态，然后从已连接的聊天入口发送一句问候。

已有伙伴时，先确认名称与目录，再选择继续使用或新增伙伴。完整重新配置前，先阅读向导的覆盖范围和备份提示。

免费档的额度和可用服务以当前安装界面及官网说明为准；自配模型需要相应服务账号和凭据。

## 路线二：npm 自托管

适合已有 Node.js 环境，或需要在服务器上部署的用户。要求 **Node.js 22 或更新版本**。

```bash
npm install -g engine7
engine7 init
```

跟随初始化提示选择目录、伙伴、模型与平台，完成模型服务和平台配置后启动：

```bash
engine7 start
```

配置参数及更多管理命令可以通过 `engine7 --help` 查看。初始化不等于已经完成平台授权，请以实际连接状态和聊天回执为准。

## 第一次交给她一个任务

在连接好的聊天入口里，先发送 `/work on`，再给出一个范围清楚的任务，例如：

> 请根据我发来的会议记录，先列出决定、待办、负责人和期限。信息不确定的地方单独标注，先给我摘要。

执行期间，如果希望改变方向：

```text
/ps 请按负责人分组，先整理下周要完成的事项
```

如果需要立即停止当前任务：

```text
/stop
```

之后可以重新说明要求。恢复自动判断交流模式使用 `/work auto`。命令输入形式与平台有关：支持原生斜杠命令的平台，可在菜单或参数表单中选择对应命令。

## 查看状态与求助

- `/model`：检查当前模型、已配置模型及备用链状态。
- `/tasks`：查看后台任务列表。
- `/context`：查看上下文使用情况。
- `engine7 --version`：在终端查看安装版本。
- `engine7 doctor`：在终端生成自检报告。

遇到问题先看 [FAQ](faq.md)，也可以在 [Issues](https://github.com/ruiyangruiyi/engine7-docs/issues) 提交去掉敏感信息的复现步骤。
