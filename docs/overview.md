# 产品概览

[返回文档首页](../README.md) · [English](en/overview.md) · [在线阅读完整产品介绍](https://www.twinsun.top/intro/)

Engine7 · 栖是一套可自托管的 AI 助理引擎。你可以在自己的电脑或服务器上运行，通过熟悉的聊天入口与她相处，把日常的想法、安排和工作交给她。

## 伙伴与相处

伙伴有自己的名字、身份与表达方式，也会逐步了解你的背景和偏好。日常交流和工作任务可以自动选择对应模式，也可以手动切换。支持语音等体验扩展，具体能力取决于所启用的扩展、模型与服务。

## 记忆与接续

mem7 长期记忆组织人物、经历、偏好与安排，保留信息的来源、时间和观点归属。长期记忆帮助助理在后续交流中理解背景，也让变化后的认识有机会更新。记忆仍需结合上下文判断，你可以直接澄清或纠正。

## 任务与协作

从一句托付到材料整理、文档、表格、PPT 或代码交付，Engine7 可以调用工具和技能推进任务。复杂工作也可以由 Agent Team 分工协作，具体执行依赖已安装的技能、材料、服务和授权。

**工作过程中，人可以随时参与。** work 模式输出进展和中间结果；`/ps` 调整运行中的方向，`/stop` 打断当前任务，`/model` 查看或切换模型。操作步骤见[可交互、可干预的任务](interactive-tasks.md)。

## 主动提醒

日历、定时任务和基于上下文的提醒，让安排有机会在合适的时候被提起。重要期限建议明确设置提醒，并确认时间、时区和投递渠道。

## 多渠道与部署

支持微信、飞书、钉钉、企业微信、Discord、Telegram、WhatsApp 等聊天平台，按平台账号及接入条件配置。Windows、macOS 和 Linux 可以采用对应安装或自托管方式；下载与首次使用见[快速开始](quick-start.md)。

工作区与持久状态由部署环境保存。更换模型与迁移工作区是两件事：模型服务负责推理，伙伴的配置、文件和记忆需要妥善保留。

## 模型与可用性

支持多种模型服务接入与手动选择。配置备用模型或服务后，可以在异常时尝试其他候选项，结合冷却和状态反馈减少对单一服务的依赖。详见[模型选择与 Fallback](models-and-fallback.md)。
