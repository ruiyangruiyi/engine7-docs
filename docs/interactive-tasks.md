# 可交互、可干预的任务

[返回文档首页](../README.md) · [模型与备用机制](models-and-fallback.md)

**任务在工作，人也能随时参与。** Engine7 的交互方式把过程观察、补充要求和打断放在一起，帮助你及时发现偏差、缩小范围，并调整接下来的工作。

## 看见工作过程

work 模式使用面向工作任务的上下文，并通过聊天渠道输出进展、工具活动和中间结果。先看摘要、先看方案、边做边检查，都可以直接写进任务要求。

输出的详细程度受聊天平台、过程显示及外部群聊设置影响。开启 work 模式后仍需确认相应渠道的显示设置。

| 命令 | 行为 |
| --- | --- |
| `/work` | 查看当前模式 |
| `/work on` | 强制使用工作模式，下一条消息生效 |
| `/work off` | 强制使用日常交流模式，下一条消息生效 |
| `/work auto` | 恢复逐条消息自动判断 |

## 中途改方向：/ps

`/ps` 向**正在运行的当前任务**注入补充要求，不必等这一轮回答结束。该命令会打断当前生成，让后续执行接收新的方向。

```text
/ps 先不要写完整方案，先给我三种可选方向
/ps 客户是非技术人员，请减少术语，突出实际收益
/ps 先处理已有资料，不要继续扩大搜索范围
```

没有运行中的任务时，直接发送普通消息即可。支持原生斜杠命令的平台，选择 `/ps` 后把要求填写到 `message` 参数中；其他支持文本命令的渠道使用 `/ps 要求内容`。

## 及时打断：/stop

`/stop` 请求停止当前会话的运行任务，并清掉该会话待处理的消息队列。收到“已停止当前任务”的回执后，可以重新发送要求。

```text
/stop
```

停止不会撤销已经完成的文件修改、消息发送等外部操作；该命令针对当前会话，其他独立任务与定时安排需分别管理。打断响应也会受到正在执行的工具和外部服务影响。

## 查看或切换模型：/model

```text
/model
/model 已配置的模型别名
/model auto
```

无参数查看当前选择、可用模型及备用链状态；选择模型时，使用列表中已有的引用或别名。手动选择会覆盖自动路由，需要恢复自动选择时使用 `/model auto`。运行中切换可能打断旧模型查询，重要任务建议先停下、确认进展后再切换。详见[模型说明](models-and-fallback.md)。

## 其他常用查看命令

| 命令 | 用途 |
| --- | --- |
| `/tasks` | 查看后台任务及其状态；这个列表不等于全部前台工作 |
| `/agents` | 查看已登记的 Agent 及其运行状态 |
| `/context` | 查看上下文使用情况 |

## 一次完整的干预过程

1. 发送 `/work on`，把任务、材料、交付格式和限制说明清楚。
2. 观察过程输出和第一份中间结果。
3. 用 `/ps` 补充要求，例如“先给摘要，先不要展开正文”。
4. 需要停止时使用 `/stop`，检查已经完成的工作，再重新交代。
5. 服务或模型不合适时，用 `/model` 查看选项；恢复备用链用 `/model auto`。

你可以在工作过程中形成判断、给出干预，并确认回执，让任务持续朝你的目标推进。
